# Fast Quality Buttons

A mod for Factorio 2.1 with Quality. Adds 5 quality shortcut buttons, normal to legendary. The selected quality is applied to assembling machine recipes and optionally to building, the pipette and ghosts. Click the active button again to turn it off.

**Download:** [Factorio Mod Portal](https://mods.factorio.com/mod/fast-quality-buttons) or the in-game mod manager.

Bugs and ideas: open an issue here or post in the Mod Portal discussion.
